# 1.2.0 — חיבור למחברת השיעור בטלפון

גרסה זו מוסיפה גשר מקומי בין האפליקציה במחשב לבין מצב "מחברת שיעור" באפליקציית האנדרואיד.

- **שרת HTTPS מקומי (ניסיוני)** — מופעל רק במפורש מההגדרות, תחת "מתקדם ← מחברת שיעור". מציג קוד זיווג חד־פעמי וטביעת אישור לאימות בטלפון.
- הקוד תקף 5 דקות וננעל אחרי 5 ניסיונות שגויים. הטוקן אקראי בן 256 ביט, ורק טקסט עובר — שום אודיו לא נשלח מהטלפון.
- נקודות לשאילת שאלה ולסיכום שיעור משתמשות בספק ה־AI המוגדר כבר בהגדרות. כשאין ספק מוגדר, הטלפון מקבל הודעה ברורה במקום תשובה ממציאה.
- השרת נכבה ביציאה מהאפליקציה ואינו נפתח אוטומטית בכניסה למערכת.

הערה: תכונה ניסיונית. התשובות מבוססות על החומר שהטלפון שולח ועלולות לטעות — תמיד לאמת מול המדריך.
